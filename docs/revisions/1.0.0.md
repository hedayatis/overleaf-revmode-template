# Revision 1.0.0: initial public release

- Date: 2026-09-02
- Status: release
- Previous revision: none

## Purpose

Publish a free, single-source LaTeX workflow that separates a working master,
a comment-driven review document and a clean submission document.

## Scope and affected components

The release includes the package, three entry points, collaborator
configuration, demonstration manuscript, documentation, local build helpers,
validation checks and GitHub Actions packaging.

## Behavioral or methodological changes

The final mode can accept or reject all pending suggestions through one package
option, with per-suggestion overrides. Already addressed text always survives
while comments, replies, private notes, line numbers and colour markup disappear.

## Data, schema, API and compatibility impact

The public macro interface is documented in `README.md` and `CHEATSHEET.md`.
This is the first release, so there is no migration requirement.

## Validation evidence

- All three main files compile with `latexmk`/pdfLaTeX.
- Text extraction checks enforce private/review/final content separation.
- Final output contains accepted text, preserves explicit rejections and removes
  revision comments.
- Dispatch ZIP contents are listed as a packaging smoke test.

## Migration instructions

None.

## Known limitations

- Replies are associated with the most recent source-order comment.
- Journal classes may impose their own restrictions on markup in moving
  arguments.
